✨ Interactive Drag & Drop Features

  • Nest Subfolders: Drag any folder over another folder to create a subfolder.
  • Reorder Hierarchy: Drag folders or feeds above/below each other to reorder.
  • Move to Root: Drag a subfolder onto the "iCloud" header area to move it to the top level.
  • Dynamic Counts: Folder counts automatically sum all direct feeds and nested subfolders!
  • Right-Click Menu: Context menu allows adding subfolders, renaming, or deleting folders.
